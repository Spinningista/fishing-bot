# Журнал уловов на спиннинг — Telegram-бот

## Что это

Бот заменяет ручное ведение таблицы в Numbers. Пишешь `/new` — и вводишь выезд
пошагово кнопками: дата → водоём → место → условия → приманка → рыба →
количество → вес → ещё улов / закончить. Все данные копятся в базе, из
которой потом строится дашборд (тот HTML-файл, что уже показывал отдельно) и
делается экспорт обратно в CSV для Numbers.

## Структура проекта

```
config.py                    — настройки (токен, id, GitHub для фото)
db.py                        — база данных SQLite, вся работа с данными
states.py                    — состояния диалога бота
keyboards.py                 — кнопки
bot.py                       — сам бот, все шаги диалога
export.py                    — выгрузка в CSV
photo_storage.py             — загрузка фото приманок в GitHub
migrate_from_numbers_csv.py  — разовый перенос твоей истории из Numbers
requirements.txt             — зависимости
Procfile                     — команда запуска для Railway/Render
.env.example                 — какие переменные окружения нужны
```

## Шаг 1. Создать бота и узнать свой id

1. Напиши в Telegram **@BotFather** → `/newbot` → следуй инструкциям →
   получишь **токен** вида `123456:ABC-DEF...`.
2. Напиши **@userinfobot** — он покажет твой **Telegram id** (число).

Это два значения, которые понадобятся дальше: `BOT_TOKEN` и `OWNER_ID`.
`OWNER_ID` нужен, чтобы бот отвечал только тебе, а не случайным людям, если
кто-то найдёт его имя.

## Шаг 2. Перенести историю из Numbers (один раз)

Локально (на своём компьютере) или прямо здесь, где угодно, где есть Python 3.11+:

```bash
pip install -r requirements.txt   # requests нужен и для миграции тоже не помешает, но сама миграция использует только стандартную библиотеку
export DB_PATH=fishing.db
python migrate_from_numbers_csv.py "Спиннинг.csv"
```

Скрипт создаст файл `fishing.db` со всей историей (у тебя это будет 1302
записи, 496 выездов, справочник из 265 приманок — ровно то, что было в
Numbers). Дальше этот файл `fishing.db` нужно будет положить туда же, где
будет жить бот на хостинге (см. ниже).

## Шаг 3. Запуск бесплатно 24/7 — Railway

1. Зарегистрируйся на [railway.app](https://railway.app) (можно через GitHub).
2. Создай новый проект → **Deploy from GitHub repo** (перед этим залей папку
   с ботом к себе на GitHub — простой способ: создать новый репозиторий и
   загрузить в него все эти файлы через веб-интерфейс GitHub, drag & drop).
3. В настройках проекта (Variables) добавь переменные окружения:
   - `BOT_TOKEN` — токен от BotFather
   - `OWNER_ID` — твой id
   - `DB_PATH` — `fishing.db`
   - (опционально) `GITHUB_TOKEN`, `GITHUB_REPO`, `GITHUB_BRANCH` — для фото
     приманок, см. Шаг 5
4. Railway сам увидит `Procfile` и `requirements.txt` и запустит бота как
   worker-процесс.
5. **Важно про базу данных**: бесплатный контейнер Railway пересоздаётся при
   каждом деплое, и файл `fishing.db`, созданный локально на Шаге 2, нужно
   либо загрузить в тот же репозиторий перед деплоем (тогда он поедет вместе
   с кодом), либо (лучше для сохранности в будущем) подключить Railway
   **Volume** — постоянный диск, который не пересоздаётся. В настройках
   проекта: **Add Volume**, примонтировать например в `/data`, и указать
   `DB_PATH=/data/fishing.db`.

Если что-то в этом шаге покажется непонятным на месте — просто пришли мне
скриншот или опиши, что видишь на экране, разберём вместе.

## Шаг 4. Проверка

Напиши боту `/start`, затем `/new` — и пройди пошагово тестовый выезд.
`/export` в любой момент выгрузит весь архив в CSV, который открывается в
Numbers (Файл → Импортировать).

## Шаг 5. Фото приманок (опционально)

1. Создай на GitHub новый репозиторий, например `fishing-photos` (можно
   приватный).
2. Settings → Developer settings → Personal access tokens → Fine-grained
   tokens → New token. Дай доступ **только** к этому репозиторию, права
   **Contents: Read and write**.
3. В переменные окружения бота добавь:
   - `GITHUB_TOKEN` — созданный токен
   - `GITHUB_REPO` — `твой_логин/fishing-photos`
   - `GITHUB_BRANCH` — `main`
4. Перезапусти бота. Теперь при добавлении новой приманки он будет
   предлагать прикрепить фото.

Без этих переменных бот прекрасно работает и без фото — просто не будет
задавать вопрос про фото.

## Дальше

всё обновлялось само после каждого выезда. Как будешь готов — скажи, сделаем.
